# San Judas Farmacia Gestor

Actúa como un desarrollador profesional de aplicaciones web. Quiero crear un sistema de información gerencial llamado "Farmacia San Judas SIG", diseñado para administrar las operaciones de una farmacia.

Diseña una aplicación web moderna, profesional, intuitiva y adaptable a computadoras.

Utiliza una combinación de colores verde, blanco y gris claro, relacionada con el sector farmacéutico.

La aplicación debe tener:

Una pantalla de inicio de sesión.

Un menú lateral de navegación.

Un dashboard para el gerente con indicadores de ventas, productos registrados, productos con bajo stock y ventas recientes.

Un módulo de productos.

Un módulo de clientes.

Un módulo de ventas.

Un módulo de inventario.

Incluye tablas, formularios, botones de agregar, editar, buscar y guardar.

Utiliza información de ejemplo temporal mientras se conecta la base de datos.

Importante: prepara una estructura organizada para conectar posteriormente Supabase. No elimines ni omitas los módulos solicitados.
